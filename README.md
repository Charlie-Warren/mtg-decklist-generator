# Decklist Generator

## Downloading a Decklist
### Moxfield
1. Go to the webpage for your moxfield deck
2. Click "More" (3 vertical dots)
3. Click "Export"
4. Click "Copy Plain Text"
5. Paste decklist into a simple text (.txt) file, for example using Notepad.

### MTGGoldfish
1. Go to the webpage for your mtggoldfish deck
2. Click "Download"
3. Click "Text File (Default)"

## Using the Application

1. Run `DecklistGenerator.exe` and input your decklist as a txt file.
2. Input all the fields and press `Generate Decklist`
3. A PDF with your decklist will be created, ready to be printed for your event.
