# Decklist Generator

## Usage
1. Go to the webpage for you moxfield deck
2. Click "More" (3 vertical dots)
3. Click "Export"
4. Click "Copy Plain Text"
5. Paste decklist into a simple text (.txt) file, for example using Notepad.
6. Run `DecklistGenerator.exe` and input your decklist as a txt file.
7. Input all the fields and press `Generate Decklist`
8. A PDF with your decklist will be created, ready to be printed for your event.
